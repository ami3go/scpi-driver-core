## Architecture assessment

The release builder now treats `pyproject.toml` as the authoritative semantic version source. The public release label is deterministically generated as `YY.RR`, where `YY` is the major component and `RR` is the zero-padded minor component. For package version `26.2.0`, the archive label is therefore `v26.02`.

The verifier is intentionally independent from the installed driver. It can validate an unpacked repository or a ZIP using only Python's standard library, which makes it suitable for CI, offline release checks, and clean workstations.
