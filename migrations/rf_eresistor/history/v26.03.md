# Release 26.03 — 2026-08-07

RFDS-008 evidence engine and RFDS-019 hardware conformance.

- Added `rf_eresistor/evidence.py`: an RFDS-008 evidence engine recording
  every public keyword call (arguments, duration, result/failure) and every
  underlying SCPI/HTTP exchange to a per-session, timestamped run directory
  under `results/session/rf_eresistor/`, with a SHA-256 evidence manifest,
  JSONL event/operation/error streams, redaction of credential-shaped
  arguments, and correlation IDs linking nested keyword calls. Traces both
  wire protocols reachable from the public keyword surface — SCPI-over-TCP
  (`EResistorClient.query()`) and HTTP (`EResistorHttpApi.get_text()`, used
  by `Ping EResistor`, `Identify EResistor`, and the calibration-download
  keywords) — by wrapping the connected client instance from the Robot
  Framework adapter layer; `eresistor_driver` itself (also used standalone
  via its own CLI) is untouched. Complements, and does not replace, the
  existing `eresistor_driver.logging_utils.AuditLogger` facility.
- Wrapped every public keyword with the new evidence recording (opt out with
  `evidence_enabled=${FALSE}`); added `Export Diagnostic Bundle` to zip a
  session's evidence for troubleshooting.
- Added `tests/hardware/verify_all_keywords.robot`: an RFDS-019 real-hardware
  conformance suite exercising all 42 public keywords against a real
  E-Resistor board, gated behind `ALLOW_ACTIVATE` (mask/resistance/
  temperature writes) and `ALLOW_DISCOVERY` (network scanning).
- Added `schemas/evidence/*.schema.json`, `docs/logging_and_evidence.md`,
  `guide/evidence_and_diagnostics.md`, and
  `scripts/validate_evidence.{py,sh,bat,ps1}`.
- Added `tests/evidence/test_evidence.py` and `tests/conftest.py`.
- Added the `Export Diagnostic Bundle` capability to `tools/generate_ai_contract.py`
  and regenerated `ai/eresistor_ai_contract.yaml`/`.lock` (42 capabilities).
