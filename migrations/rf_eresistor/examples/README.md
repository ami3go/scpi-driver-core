# Examples

The numbered files progress from read-only checks to state-changing operations. All accept `${ERESISTOR_HOST}` (default `192.168.0.55`). Start with 01, then electrically validate 03 before using resistance/temperature examples.

1. Identity and status
2. Set calibrated resistance
3. Direct mask control
4. All-channel mask update
5. Atomic multi-channel resistance update
6. Save calibration
7. Load cached calibration
8. Temperature emulation
9. Network discovery
10. Error queue and raw SCPI
11. Watchdog and metrics
12. Safe-output teardown pattern
