# RF E-Resistor 26.03

Production-oriented Robot Framework control of an eight-channel E-Resistor matrix.
Release 26.03 adds an RFDS-008 structured evidence engine (`rf_eresistor/evidence.py`)
tracing both of this driver's wire protocols (SCPI-over-TCP and HTTP) and a real-hardware
RFDS-019 conformance suite covering all 42 public keywords. See
[Logging and evidence](logging_and_evidence.md).
