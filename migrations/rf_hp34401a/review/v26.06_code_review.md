# Code review — v26.06

## Finding

The v26.05 HIL suite used an embedded library listener and in-memory result dictionary. On the tested Robot runtime, successful nested driver calls and disabled-profile exclusions were not present in the finalizer state, causing executed APIs to be reported as `NOT RUN`.

## Correction

- Introduced an explicit Robot listener registered by the launcher.
- Persisted each keyword result and exclusion atomically to a run-local JSON state file.
- Merged persisted state during finalization.
- Registered profile exclusions in suite setup.
- Separated report generation from acceptance assertion.

## Review verdict

The correction is backward compatible and localized to HIL evidence orchestration. No instrument command implementation or public API signature changed.
