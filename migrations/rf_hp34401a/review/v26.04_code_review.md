## Open controlled deviations

1. The shared approved `rfds-core` package is not available in this build environment. The driver implements compatible semantics locally but does not claim RFDS-003 v2 full conformance.
2. The incorporated production core uses its established text-oriented transport API. A full RFDS-004 v2 byte-boundary migration is deferred because it is an architectural change requiring separate HIL regression.
3. Official Robot Framework, Libdoc, MkDocs, and physical HIL evidence for the final bytes are pending release-site execution.
4. GitHub Action references remain major-version tags rather than immutable SHAs and require repository release-hardening before P1.
