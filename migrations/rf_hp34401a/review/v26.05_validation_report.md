# rf_hp34401a v26.05 validation report

## Defect reproduced from user evidence

The v26.04 real-hardware suite received lowercase CLI string `true` and passed it directly to Robot/Python expression evaluation. Setup failed with `NameError: name 'true' is not defined`, after which teardown misleadingly marked all 108 APIs `NOT RUN`.

## Correction

- Central case-insensitive Boolean normalization added.
- `HIL_ENABLED`, `FAIL_ON_EXCLUSIONS`, and all eleven hardware profile flags normalized during suite setup.
- Invalid values fail before coverage start and before hardware access.
- Launchers emit `True`/`False`.
- Coverage starts only after HIL enablement and VISA-resource preflight.
- Teardown finalizes coverage only when coverage actually started.
