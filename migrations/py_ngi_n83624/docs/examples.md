# Examples

The `examples/` folder contains fourteen Robot Framework suites:

1. Emulator smoke test
2. TCP identification
3. Safe source-mode cycle
4. Charge mode
5. Measurement assertions
6. Multi-channel measurement
7. SOC profile
8. Sequence profile
9. Protection and capture rate
10. Heartbeat and communication health
11. Serial identification
12. Channel-specific UDP
13. Guarded raw SCPI
14. JSONL audit log

Run an offline example:

```bash
./scripts/run_example.sh examples/01_emulator_smoke.robot
```
