# RS-232 setup

Supported instrument configurations are 9600/4800/2400/1200/600/300 baud with two stop bits. Valid parity/data combinations are none/8, even/7, and odd/7. Use a proper null-modem cable if required by the bench wiring. The default library settings are 9600 baud, no parity, 8 data bits, 2 stop bits, and DTR/DSR flow control.
